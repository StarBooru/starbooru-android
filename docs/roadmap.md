# Roadmap

_Status as of 2026-11-22: docs only. Scope comes from starbooru-server's `docs/checklist.md` › android app._

## 1. Foundation

- [ ] Gradle project, the Rust core with UniFFI, lints, CI
- [ ] Theme from the wallpaper or the seed hue, light and dark
- [ ] Sign-in to the self-hosted instance, with a password and with a provider
- [ ] Gallery: grid, infinite scroll, sorts
- [ ] Viewer: image, GIF and video, pinch zoom, swipe to the previous and next post, pull down to close

## 2. Daily use

- [ ] Search with tag autocomplete and typo correction
- [ ] Upload from the photo picker and the share sheet, in chunks, finishing in the background
- [ ] Download to the gallery
- [ ] Tag editor, explore, saved searches, votes, related posts, recycle bin
- [ ] Media cache on disk with a size limit
- [ ] Waits out the server's and other sites' rate limits (in `starbooru-client`)

## 3. Everything the reference had

- [ ] Other boorus and library imports
- [ ] People in a post, the editor, the duplicate finder, share links
- [ ] Settings and administration

## 4. Android

- [ ] Tablet layout, left and right hand
- [ ] Originals on dense screens, samples elsewhere
- [ ] Battery optimizations
- [ ] Sweet animations
- [ ] English and Italian
- [ ] Updates in the app
- [ ] Sync
